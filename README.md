## 📖 About

A gallery of **pure HTML** exercises: text elements, lists, tables,
forms, links, images, block/inline behaviour and semantic elements —
each concept in its own file for quick reference.

## ✨ Features

- One page per HTML topic
- Covers semantic markup and forms
- No frameworks or build tools
